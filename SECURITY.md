# Security policy

Please use the latest release or current `main` for security fixes. This dashboard
is intended for private networks, localhost, or access through a trusted HTTPS proxy.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/tugcantopaloglu/openclaw-dashboard/security/advisories/new)
when available. If private reporting is unavailable, open a minimal issue asking
for a private reporting channel. Do not include credentials, recovery tokens,
private agent messages, or a working exploit in a public issue.

Include the dashboard commit/release, Node.js version, deployment type, affected
endpoint, prerequisites, impact, and a minimal reproduction using synthetic data.
